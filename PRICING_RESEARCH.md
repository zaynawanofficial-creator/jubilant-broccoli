# PRICING_RESEARCH — how package prices were set (2 Nov 2026)

## Positioning
The owner set the anchors: citation/profile links start at **$1 per link**, and guest posts run **DR10+ $10 / DR20+ $25 / DR30+ $49 / DR50+ $89**. That puts SEO Booster in the **budget-marketplace band** (Fiverr / Upwork level), well below agency pricing.

Claude priced every other service in the same band so the catalogue reads as one consistent brand:
- Entry packages are cheap, to win first orders.
- Volume tiers carry a discount, to raise average order value.
- Monthly work is sold as fixed "1 month" products. Recurring billing is not set up (it would need the WooCommerce Subscriptions licence).

All prices are editable in wp-admin, so no code change is needed to adjust them.

## Risks to watch
- **Guest post margin.** Real DR50+ placements usually cost resellers more than $89, so fulfilment at these prices depends on low-cost link sellers. Check supplier cost per tier before scaling ads, and check publisher quality, since cheap high-DR sites are often link farms. Google treats paid links without `rel="sponsored"` as link spam (https://developers.google.com/search/docs/essentials/spam-policies). Our copy promises no rankings, dofollow or permanence.
- **Budget pricing attracts price shoppers.** Bundles and the featured tiers (20 and 50 links, DR30+, 5-page site, Full Brand Identity) steer buyers to higher order values.
