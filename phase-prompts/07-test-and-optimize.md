# 07 — Test, optimize, and secure
Use Playwright or an equivalent browser harness to test real routes, page states, navigation, mobile menu, group tabs, package quantity changes, cart totals, coupon rules, valid/invalid checkout, accessible form errors, confirmations, customer/admin portal, broken images/links, contact form routing and failed payment. Check at 360/390/768/1024/1440 widths plus keyboard-only navigation and reduced motion. Capture screenshots and compare them. Run static analysis, unit/integration tests, PHP/JS checks, accessibility checks, console/network checks, secure upload tests, webhook replay/idempotency where applicable. Check performance field targets LCP <= 2.5s, INP <= 200ms, CLS <= 0.1; distinguish lab checks from real field measurements. For WordPress caching exclude cart/checkout/account and test sessions. Record exact results and failures in TEST_REPORT.md and FIX_LOG.md. Fix blockers and retest. Do not claim passing tests that were not run.
