# 05 — Payments, brief collection and client delivery
Complete a sandbox transaction with the actual supported payment gateway in a nonproduction environment. Check jurisdiction, company eligibility, processor permissions, currency, taxes, payment-method display, hosted checkout and return flow. Never assume Stripe credentials or activate live charges. Implement product-specific intake: off-page target URLs/keywords/business NAP, web project pages/features/access preferences, content topic/audience/word count/tone, design reference/asset uploads. Require minimum safe fields at checkout and longer intake through protected post-order form. Store submitted details against order; send buyer/admin confirmation and brief reminders; show a brief-completion badge. Implement order statuses or compatible custom workflow, delivery files, client review, ticket/response trail, admin fulfillment, refunds and cancellations; keep underlying payment status correct. Security: sanitize, validate, authorize downloads, secure files, file limits, PII retention and no plaintext login credentials. Acceptance: pass gateway test for successful/failed/refunded payments, brief linkage, admin access permissions, emails and no exposed private uploads.
