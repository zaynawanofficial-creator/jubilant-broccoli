**Plugin 0.2.0** (`dist/seo-booster-core.zip`):
- `[sb_from]` shows live "from" prices, so no prices are hard-coded in page content.
- `[sb_breadcrumbs]` outputs breadcrumbs plus BreadcrumbList JSON-LD.
- `[sb_year]`.
- `[sb_lead_form type=contact|quote]`:
  - spam protection: nonce, honeypot, minimum fill time, per-IP rate limit
  - consent checkbox, private **Leads** inbox in wp-admin, email to the admin
  - page-cache bypass
- SEO head tags, only when no SEO plugin is active: meta description from excerpts, canonical, Open Graph, Organization + WebSite JSON-LD.
- `noindex,follow` on cart, checkout, account, product, shop and search pages.
- Product pages: the importer writes a full description (included, not included, requirements, delivery, link back to the service page). Quote-only products get a "Get a quote" button.
- **Bug fixed:** plugin CSS classes collided with theme classes, so the theme's grids turned into swipe rows on mobile. Plugin classes renamed to `sb-pk*`.

## Access diagnosis · 2 Nov 2026
- A third Application Password, created on the WoodMart MCP screen for `admin`, was also rejected from this container.
- Evidence the passwords are not the problem:
  - Unauthenticated `GET /wp-json/` through the session proxy returns `401 incorrect_password`.
  - The same request made directly returns `200`.
  - `/wp-json/wc/store/v1/products` (public, ignores auth) returns 200 through the proxy.
- Conclusion: the cloud session's egress path changes the `Authorization` header on requests to seobooster.uk. Not bypassed, per the proxy rules.
- Owner is installing `seo-booster-core.zip` manually (zip delivered).
