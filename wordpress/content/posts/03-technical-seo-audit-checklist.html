A technical SEO audit checks whether search engines can find, crawl, render and index your website efficiently — and whether real users get a fast, stable experience. It’s the foundation every other SEO effort sits on. Here are the 25 checks we run on every client site, grouped by priority.

Priority 1: crawling and indexing

  1. Robots.txt isn’t blocking important pages, CSS or JavaScript.
  2. XML sitemap exists, is submitted in Search Console and only lists indexable, 200-status URLs.
  3. Index coverage: review Search Console’s Pages report for “Crawled – currently not indexed” and “Excluded” surprises.
  4. Noindex tags are only on pages that should be hidden (cart, checkout, thank-you pages).
  5. Canonical tags point to the preferred version of each page.
  6. One version of the site: HTTP, HTTPS, www and non-www all 301 to a single canonical origin.
  7. Status codes: no important pages returning 404 or 5xx errors.

Priority 2: speed and Core Web Vitals

  1. Largest Contentful Paint under 2.5 seconds on mobile.
  2. Interaction to Next Paint under 200 milliseconds.
  3. Cumulative Layout Shift under 0.1 — set width and height on images and embeds.
  4. Images compressed, in modern formats (WebP/AVIF) and lazy-loaded below the fold.
  5. Render-blocking CSS and JavaScript minimised; unused plugins removed.
  6. Caching and a CDN enabled; server response time (TTFB) under 600ms.

Google’s Web Vitals documentation explains each metric in detail.

Priority 3: site structure and internal links

  1. Every important page is reachable within three clicks of the homepage.
  2. No orphan pages — every page has at least one internal link pointing to it.
  3. Redirect chains and loops are flattened to a single 301.
  4. Broken internal links are fixed at the source, not just redirected.
  5. Clean, descriptive URLs without parameters for content pages.
  6. Breadcrumbs on deeper pages for users and search engines.

Priority 4: on-page technical elements

  1. Unique title tags and meta descriptions on every indexable page.
  2. One H1 per page with a logical H2–H3 hierarchy.
  3. Duplicate and thin content consolidated or improved.
  4. Image alt text that describes the image.

Priority 5: enhancements

  1. Structured data (Organization, Product, Article, FAQ, Breadcrumb) validates in Google’s Rich Results Test.
  2. Mobile usability: readable text, tappable buttons, no horizontal scrolling.

How to prioritise what you find

Audits often surface hundreds of issues. Fix in this order: anything stopping important pages being indexed, then speed problems on your highest-traffic templates, then structural and internal linking issues, and finally enhancements like schema. One template fix can resolve thousands of URLs at once — always look for the root cause.

Final thoughts

Technical SEO isn’t glamorous, but it multiplies the return on everything else you do. A fast, crawlable, well-structured site lets your content and backlinks do their job.
